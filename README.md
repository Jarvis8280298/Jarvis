# JARVIS 3.0 — iPhone PWA
This is a Progressive Web App package designed for Safari/Home Screen use.

## Install
Host these files on an HTTPS website, open the site in Safari on iPhone, tap Share → Add to Home Screen.

The app includes a web manifest, standalone display mode, iPhone metadata, service-worker caching, voice input when supported, speech output, tasks, and local memory.

## Important
A PWA needs to be served from a web origin for the full install/offline behavior. Opening a local HTML file is not equivalent to hosting the PWA. No private AI API key is included.
